# Assignment 03 — Verilog User-Defined Primitives

This document is an English translation of the original Persian assignment
handout.

## Problem 1 — Boolean Expression as a UDP

Design and implement a user-defined primitive that evaluates the following
Boolean expression:

```text
(a AND (b XOR c)) OR (NOT (c AND d))
```

## Problem 2 — Priority Encoder

Using an appropriate set of user-defined primitives, implement a four-input
priority encoder with a separate enable input.

## Problem 3 — T Flip-Flop

Implement a user-defined primitive that behaves like a positive-edge-triggered
T flip-flop with asynchronous `Set` and `Reset` inputs.

## Problem 4 — N-Bit Counter

Using the flip-flop designed in Problem 3, implement an N-bit counter with a
reset input.
