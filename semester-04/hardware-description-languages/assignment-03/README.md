# Assignment 03 — Verilog User-Defined Primitives

**Course:** Hardware Description Languages and Circuits  
**Semester:** Spring 2023  
**Tools:** Verilog, Xilinx ISE

This assignment focuses on combinational and sequential user-defined primitives
(UDPs), including truth-table descriptions, edge-sensitive behavior, and
asynchronous control inputs.

| Problem | Topic | Archived solution |
|---|---|---|
| 1 | UDP for a Boolean expression | Yes |
| 2 | Four-input priority encoder with enable | Yes |
| 3 | Positive-edge-triggered T flip-flop with asynchronous set and reset | Yes |
| 4 | N-bit counter constructed from the T flip-flop | Not present in the submitted archive |

The English version of the assignment is available in [`prompt.md`](prompt.md).
The available solutions are grouped by problem under
[`original-submission`](original-submission).
