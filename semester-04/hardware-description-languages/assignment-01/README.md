# Assignment 01 — Verilog Fundamentals

**Course:** Hardware Description Languages and Circuits  
**Semester:** Spring 2023  
**Tools:** Verilog, Xilinx ISE

This assignment introduced structural, hierarchical, RTL, and behavioral
modeling in Verilog. The exercises cover:

- constructing logic gates from two-input NOR gates;
- modeling and testing a JK flip-flop;
- building a hierarchical 16-bit comparator from 4-bit comparators;
- describing a four-function arithmetic logic unit;
- implementing an eight-bit bidirectional shift register; and
- calculating integer quotient and remainder without division operators.

The English version of the assignment is available in [`prompt.md`](prompt.md).
Solutions are grouped by problem under [`original-submission`](original-submission).
