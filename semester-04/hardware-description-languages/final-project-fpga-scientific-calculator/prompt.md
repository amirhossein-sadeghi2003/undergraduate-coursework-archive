# Final Project — Engineering Calculator

This document is an English translation of the relevant section of the original
Persian course project brief.

## Required functions

Implement a calculator with the following capabilities:

1. addition and subtraction of floating-point numbers;
2. multiplication and division of floating-point numbers;
3. calculation of sine and cosine using the CORDIC method; and
4. exponentiation and calculation of the base-2 logarithm.

The calculator must receive its input and display its output through a serial
interface.

## Target hardware

All developed code must be executable on the XUPV5-LX110T FPGA board. The
hardware laboratory may be used during the times announced by the teaching
assistants to implement and test the modules on the board.

## Expected submission

Each student must submit an individual ZIP archive containing:

- a short report describing the design and implementation and introducing the
  main parts of the code;
- the source code with any necessary explanations; and
- the complete synthesized project with an output that can be programmed onto
  the board.
