# Hardware Description Languages and Circuits

**Semester:** Spring 2023  
**Primary language:** Verilog  
**Development environment:** Xilinx ISE

This directory archives four assignments from an undergraduate course in
hardware description languages and digital-circuit modeling. The coursework
progresses from gate-level and hierarchical descriptions to timing analysis,
user-defined primitives, and finite-state-machine design.

## Assignments

| Assignment | Main topics |
|---|---|
| [Assignment 01](assignment-01) | NOR-based logic, JK flip-flop, hierarchical comparator, ALU, shift register, and loop-based divider |
| [Assignment 02](assignment-02) | Propagation delay, ripple-carry and carry-lookahead adders, tasks, and functions |
| [Assignment 03](assignment-03) | Combinational and sequential user-defined primitives |
| [Assignment 04](assignment-04) | Sequence detection and finite-state-machine controllers |

Each assignment includes an English translation of its original Persian prompt
and the source files that were available in the corresponding submission
archive.

## Final project

- [FPGA Scientific Calculator Prototype](final-project-fpga-scientific-calculator) — Seven-member group project exploring floating-point arithmetic, CORDIC sine and cosine, memory-based input, and FPGA integration.

## Archive policy

The code in `original-submission` is preserved as submitted in 2023. Filenames,
file extensions, and directory layout were standardized in 2026 to make the
archive easier to browse. Missing solutions are identified in the README for
the relevant assignment rather than reconstructed later.
