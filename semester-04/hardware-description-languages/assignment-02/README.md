# Assignment 02 — Timing, Adders, Tasks, and Functions

**Course:** Hardware Description Languages and Circuits  
**Semester:** Spring 2023  
**Tools:** Verilog, Xilinx ISE

This assignment covers propagation delays in combinational logic, two adder
architectures, and reusable Verilog subprograms.

| Problem | Topic | Archived solution |
|---|---|---|
| 1 | Eight-bit ripple-carry adder with gate delays | Yes |
| 2 | Carry-lookahead adder and worst-case timing | Not present in the submitted archive |
| 3 | Integer logarithm implemented as a task | Yes |
| 4 | Factorial implemented as a function | Yes |

The English version of the assignment is available in [`prompt.md`](prompt.md).
The available solutions are grouped by problem under
[`original-submission`](original-submission).
