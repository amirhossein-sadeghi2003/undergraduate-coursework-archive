# Advanced Programming

Coursework from the Advanced Programming course, completed during the Spring 2023 semester of the B.Sc. in Computer Engineering at Isfahan University of Technology.

## Project

- [Qt Messenger Client](final-project-qt-messenger) — A three-member group project implementing a graphical client for a course-provided messaging server.

The project applies C++ object-oriented programming, Qt Widgets, asynchronous HTTP requests through Qt Network, JSON response handling, and basic local file persistence.
