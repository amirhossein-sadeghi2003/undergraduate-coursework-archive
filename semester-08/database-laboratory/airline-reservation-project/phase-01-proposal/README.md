# Phase 1 - Proposal

The first phase defined the project topic, expected user needs, candidate entities, and relationships. The initial scope resembled the Alibaba travel platform and included airline tickets, train tickets, hotels, rooms, reservations, and payments.

The instructor later requested a smaller project. Phase 2 and the final application therefore implement only the airline-reservation portion.
