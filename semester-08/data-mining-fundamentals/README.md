# Fundamentals of Data Mining

This directory archives the final project completed for the undergraduate Fundamentals of Data Mining course during the Spring 1403-1404 academic term.

## Course archive

- **Work type:** Three-person team project
- **Presentation:** Presented in class using the Jupyter Notebook
- **Primary language:** Python
- **Main libraries:** pandas, NumPy, Matplotlib, Seaborn, and scikit-learn
- **Task:** Binary classification of loan-default risk

## Project

| Project | Main focus | Archival status |
| --- | --- | --- |
| [Credit Risk Classification](credit-risk-classification/) | Exploratory analysis, preprocessing, feature engineering, Decision Tree pruning, SVM tuning, and model comparison | Preserved with embedded outputs; original CSV dataset was not available, so execution could not be reproduced |

## Portfolio use

The project is useful evidence of introductory data-mining coursework, collaborative work, and classroom presentation experience. It should remain inside the coursework archive rather than being presented as a standalone flagship machine-learning repository. Any CV reference must identify it as a three-person project.
