# Lab 01 — Linux files and processes

## Contents
The historical submission contains four question directories with command logs, reports, created files, process snapshots, and an SSH/SCP exercise.

## Archival review
This is an introductory Linux lab rather than a standalone project. The submission is retained because it documents the beginning of the course progression. Some command logs contain typos or incomplete steps, including `systemctl open ssh` and a malformed `mv` command. The browsable copy also contains historical private-LAN host information used inside the university lab.

No attempt was made to correct the original command/report files.
