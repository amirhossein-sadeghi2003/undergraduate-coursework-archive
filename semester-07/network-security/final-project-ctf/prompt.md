# Assignment Summary - Network Security Final CTF

The original Persian project brief is preserved in `reference-material/network-security-ctf-project-fa.pdf`.

Students received access to an authorized university CTF platform and were given the following challenges:

- Sanity Check
- Mail Server - Initial Access
- Website - Initial Access
- VPN Server - Initial Access
- PC3 - Lateral Movement
- PC2 - Lateral Movement
- Project Management - Privilege Escalation

The assignment required:

- solving the mandatory Sanity Check;
- solving four of the six main challenges for full credit; and
- writing a short technical write-up for each of four solved main challenges.

The historical submission contains the mandatory Sanity write-up plus four main challenge write-ups: Website, Mail Server, VPN Server, and PC3.
