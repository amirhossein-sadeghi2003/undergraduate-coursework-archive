# Mininet OpenFlow Flow-Rule Coursework

Individual **Computer Networks II** coursework completed at Isfahan University of Technology in 2024.

## Overview

This project uses **Mininet** and **Open vSwitch** to build a small software-defined network and manually install OpenFlow forwarding rules.

The submitted Python program creates a topology with three hosts and three switches, connects the switches in a line, installs explicit flow entries with `ovs-ofctl`, tests host connectivity with `ping`, and measures UDP throughput between selected host pairs using Mininet's `iperf` helper.

## Implemented in the submitted version

The submitted `project3.py` creates:

- 3 hosts: `h1`, `h2`, and `h3`
- 3 switches: `s1`, `s2`, and `s3`
- a remote controller at `127.0.0.1:6633`
- host-to-switch links
- inter-switch links `s1-s2` and `s2-s3`

The script then installs hard-coded OpenFlow rules for two bidirectional traffic paths:

- `h1 <-> h2`
- `h3 <-> h2`

The rules are added directly to Open vSwitch with `ovs-ofctl add-flow`.

The script also:

- tests connectivity with `ping`
- runs UDP `iperf` tests for `h1-h2` and `h3-h2`
- opens the Mininet CLI for interactive inspection

## Running the historical project

The script expects a Linux environment with Mininet and Open vSwitch, plus a compatible remote controller listening at:

```text
127.0.0.1:6633
```

A typical invocation is:

```bash
sudo python3 source/project3.py
```

Because the program installs OpenFlow rules using `ovs-ofctl`, exact behavior depends on the Open vSwitch/OpenFlow versions and port numbering in the recreated topology.

## Known limitations

- The topology is intentionally small: three hosts and three switches.
- Flow rules are hard-coded for the submitted topology rather than generated by a routing algorithm.
- No controller application is included.
- The controller IP and port are hard-coded.
- The program explicitly tests only the `h1-h2` and `h3-h2` pairs in the archived source.
- The project demonstrates manual SDN forwarding configuration rather than a general-purpose routing or traffic-engineering system.
- Historical screenshots may reflect a slightly different run or intermediate version of the coursework; the README describes the archived source code itself.
