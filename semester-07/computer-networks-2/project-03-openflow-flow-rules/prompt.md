# Assignment Summary — Computer Networks II Project 03

The original Persian assignment is preserved in `reference-material/computer-networks-2-project-03-fa.pdf`.

The assignment requested an **individual** Mininet/OpenFlow project with the following tasks:

- design a topology containing 3 hosts and 3 switches;
- include a diagram of the designed topology in the report;
- create the topology using Python;
- run the topology in Mininet;
- test connectivity between hosts using `ping`;
- evaluate network links using `iperf`; and
- define paths with minimal overlap and configure the switches so that two traffic flows traverse the selected paths.

The required submission included the written report and the Python implementation.
