# Assignment Summary — Computer Networks II Project 02

The original Persian assignment is preserved in `reference-material/computer-networks-2-project-02-fa.pdf`.

## Wireshark and Mininet analysis

The assignment asked students to:

- run predefined Mininet topologies;
- inspect switch-controller traffic in Wireshark;
- identify and explain OpenFlow feature request/reply messages;
- identify Packet-In messages and explain when they are generated;
- test host connectivity using `ping`; and
- explain several Mininet command-line topology configurations.

## Python topology implementation

A custom topology had to be created using Python and Mininet.

The submitted topology was then tested using commands and operations such as:

- `ping`;
- `pingall`;
- `dump`; and
- `nodes`.

Students were also asked to submit screenshots and a short video demonstrating the topology creation and execution.

The assignment explicitly states that the project was individual coursework.
