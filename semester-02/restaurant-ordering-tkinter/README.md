# Restaurant Ordering Application

Individual final project for the Introduction to Programming course, completed during the second semester of the 2021–2022 academic year.

## Overview

This local desktop application simulates a basic restaurant ordering and inventory workflow. It allows an operator to initialize food inventory, register customer orders, validate available stock, calculate the final price, and save order information in text files.

## Features

- Graphical interface built with Tkinter
- Initial inventory registration
- Customer order entry
- Stock availability validation
- Automatic inventory updates
- Final price calculation
- Customer name and phone number recording
- Text-file storage for orders and remaining inventory

## Technologies

- Python
- Tkinter
- Text-file persistence

## Running the Application

Run `python3 restaurant_ordering_app.py` from this directory. A Python installation with Tkinter support is required.

This directory preserves the original coursework submission. Only the filename and documentation were updated when the project was archived.
