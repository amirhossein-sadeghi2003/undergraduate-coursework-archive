# Undergraduate Coursework Archive

Selected course projects completed during my B.Sc. in Computer Engineering at Isfahan University of Technology.

Projects are organized by semester. Older submissions are intentionally preserved close to their original form so the repository reflects the progression of my technical experience over time.

The Git history begins in 2026, when these files were collected from the university course system and archived on GitHub. Each project README states its original academic context and approximate completion date.
