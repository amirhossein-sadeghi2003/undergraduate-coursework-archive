# Data Structures

Coursework from the Data Structures course, taken during the Fall 2023 semester of the B.Sc. in Computer Engineering at Isfahan University of Technology. The final project specification is dated February 2024.

## Project

- [KD-Tree Pizza-Shop Locator](final-project-kd-tree-pizza-shop-locator) — A two-member C++ project using spatial and name-based data structures to manage and query pizza-shop locations.

The project applies object-oriented design, a custom two-dimensional KD-tree, recursive nearest-neighbor search, hashing, geometric region checks, and manual multi-file C++ implementation.
