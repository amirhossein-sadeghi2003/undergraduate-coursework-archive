# Assignment Overview

1. Build and address the multi-router topology shown in the assignment.
2. Configure the specified OSPF process IDs, wildcard masks, and areas.
3. Test reachability and explain missing routes between separate OSPF domains.
4. Redistribute routes between OSPF processes on R3.
5. Configure an OSPF virtual link to restore backbone connectivity.
6. Add the R1-R3 area 3 path, vary interface bandwidth, and analyze OSPF cost and route selection.
7. As a bonus comparison, replace OSPF with RIPv2 and contrast hop-count behavior with OSPF cost-based routing.
