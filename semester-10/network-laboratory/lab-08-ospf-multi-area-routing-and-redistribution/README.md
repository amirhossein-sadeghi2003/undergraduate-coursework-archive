# Lab 08 - Multi-Area OSPF, Redistribution, and Route-Cost Analysis

This lab implemented multiple OSPF processes and areas, redistributed routes between processes, repaired backbone connectivity with a virtual link, and compared OSPF cost behavior with RIP hop-count routing.
