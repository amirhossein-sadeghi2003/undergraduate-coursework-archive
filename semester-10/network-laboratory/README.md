# Network Laboratory

Individual coursework from the undergraduate Network Laboratory course, completed with Cisco Packet Tracer, Wireshark, and Linux networking tools.

## Contents

| Lab | Topic | Main artifacts |
| --- | --- | --- |
| 01 | Network analysis and Wireshark | Persian report, PCAP capture |
| 02 | VLANs, trunks, and VTP | Packet Tracer topology, switch configurations, Persian report |
| 03 | EtherChannel, inter-VLAN routing, and DHCP | Packet Tracer topology, Persian report |
| 04 | Router-on-a-stick and static routing | Packet Tracer topology, Persian report |
| 05 | Port security and access control | Packet Tracer topology, Persian report |
| 06 | Secure switching, DHCP, SSH, and spoofing analysis | Packet Tracer topology, Persian report |
| 07 | RIP dynamic routing and route analysis | Packet Tracer topology, Persian report |
| 08 | Multi-area OSPF, redistribution, and route-cost analysis | Three Packet Tracer snapshots, Persian report |

Each lab includes a concise English overview and the original Persian instruction and pre-lab material. Editable report sources were intentionally omitted because the PDF reports are the canonical submissions.

The course final project is maintained as a separate repository and is therefore not duplicated here.

## Notes

- Reports preserve the submitted technical work while removing the student identification number.
- Packet Tracer files require Cisco Packet Tracer to open.
- Documented simulator limitations and intentionally unperformed security tests are retained for accuracy.
