# Assignment Overview

1. Rebuild and harden the switched topology with VLANs, trunks, EtherChannel, and unused-port isolation.
2. Configure inter-VLAN routing and DHCP service on the multilayer switch.
3. Enable SSH and restrict VTY access to the authorized VLAN with an ACL.
4. Examine DHCP spoofing/starvation risks only in an isolated Linux environment.
5. Perform and observe a tightly scoped IP source-spoofing test with packet-capture tools.
