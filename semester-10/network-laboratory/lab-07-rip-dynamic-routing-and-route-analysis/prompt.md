# Assignment Overview

1. Build and address a three-router topology with direct, switched, and loopback networks.
2. Configure RIPv1 and explain failed reachability across discontiguous subnets.
3. Migrate to RIPv2, disable automatic summarization, and repeat the tests.
4. Inspect RIP updates, learned routes, protocol state, and equal-cost paths.
5. Add a default route and modify RIP update, invalid, hold-down, and flush timers.
