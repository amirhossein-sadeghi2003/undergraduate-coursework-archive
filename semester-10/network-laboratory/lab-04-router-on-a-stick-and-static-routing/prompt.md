# Assignment Overview

1. Configure the specified VLANs, access ports, trunks, and EtherChannel links.
2. Establish 802.1Q router subinterfaces for router-on-a-stick inter-VLAN routing.
3. Verify connectivity before and after routing is enabled.
4. Add the ISP-side topology and loopback network.
5. Configure static and default routes and validate the resulting paths.
