# Lab 02 - VLANs, Trunking, and VTP

This lab configured a multilayer distribution switch and two access switches, with management addressing, VLAN segmentation, access ports, trunks, and VTP-related verification.

## Included artifacts

- `sanitized-submission/report-fa.pdf`: Persian lab report with the student ID removed.
- `sanitized-submission/session-02.pkt`: Packet Tracer topology.
- `sanitized-submission/configs/`: normalized running configurations for ALS1, ALS2, and DLS1.
- `reference-material/`: original Persian instruction and pre-lab PDFs.

## Review notes

The topology and configuration exports consistently show access-port assignments, VLAN 99 management interfaces, native-VLAN trunking, and unused ports in shutdown state. VTP state is stored separately by Packet Tracer and is not fully represented in the running-configuration text exports.
