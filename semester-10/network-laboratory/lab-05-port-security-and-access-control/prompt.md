# Assignment Overview

1. Build the three-switch topology and create the Finance, Management, Engineering, Native, and Black-Hole VLANs.
2. Configure trunks, allowed VLANs, and a PAgP EtherChannel.
3. Place unused access ports in the Black-Hole VLAN.
4. Configure Layer 3 switch interfaces and verify inter-VLAN connectivity.
5. Enable sticky port security in restrict mode and demonstrate a MAC-address violation.
6. Enable lab-only Telnet access, then use an ACL to block the specified source from reaching the management interface.
