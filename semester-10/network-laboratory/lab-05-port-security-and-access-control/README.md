# Lab 05 - Port Security and Access Control

This lab hardened a switched network with unused-port isolation, sticky MAC learning, port-security violation handling, and an ACL-controlled management path.

## Review notes

The report documents PAgP EtherChannel, native and allowed VLANs, Black-Hole VLAN placement, inter-VLAN routing, sticky MAC learning in restrict mode, and an observed `PSECURE_VIOLATION`. Telnet was used because it was required by the lab; SSH should be preferred for real management networks.
